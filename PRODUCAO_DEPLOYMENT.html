🚀 PRÓXIMOS PASSOS

Passo 1: Gerar Builds

cd pulyn_app flutter clean flutter pub get # APK (para testes) flutter build apk --release # AAB (para Play Store - obrigatório) flutter build appbundle --release # IPA (para App Store) flutter build ios --release

Passo 2: Testar em Device Real

flutter run --release # Testar: # ✓ Login # ✓ QR Code scanning # ✓ NFC reading # ✓ Mapa em tempo real # ✓ Ranking # ✓ Sem crashes

Passo 3: Google Play Store

  1. Abra Google Play Console (https://play.google.com/console)
  2. Selecione "Pulyn Family"
  3. Vá em Release → Production
  4. Clique "Create new release"
  5. Upload do arquivo app-release.aab
  6. Preencha:
    • Release notes (português)
    • Screenshots (5+, 1080x1920px)
    • Ícone (512x512px)
    • Descrição
    • Categoria: Family
    • Faixa etária: 4+
    • Privacy Policy
  7. Clique "Review and rollout"
⏱️ Tempo de Aprovação: 2-3 horas (geralmente)

Passo 4: Apple App Store

  1. Abra Xcode
  2. Abra projeto: ios/Runner.xcworkspace
  3. Menu: Product → Archive
  4. Quando pronto, clique "Distribute App"
  5. Selecione "App Store Connect"
  6. Automatic signing
  7. Abra App Store Connect (https://appstoreconnect.apple.com)
  8. Vá em "Pulyn Family" → Builds
  9. Selecione seu build e preencha:
    • Release notes
    • Screenshots (5+, 1242x2688px)
    • Ícone
    • Descrição
    • Keywords
    • Privacy Policy
  10. Clique "Submit for Review"
⏱️ Tempo de Aprovação: 24-48 horas
